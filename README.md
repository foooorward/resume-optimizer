# 简历优化工作台

粘贴岗位 JD、填写个人信息，自动评估岗位匹配度并给出简历优化建议，导出适配该岗位的简历。

**在线使用：** https://foooorward.github.io/resume-optimizer/

## 怎么使用

页面顶部有四个标签页，按顺序走一遍即可：

| 步骤 | 标签页 | 做什么 |
| --- | --- | --- |
| 1 | **岗位 JD** | 把招聘信息原文整段粘贴进来，自动解析岗位名、公司、学历年限门槛、职责与加分项，并提取技能关键词，标注你已覆盖和还缺哪些 |
| 2 | **我的信息** | 填写基本信息、教育、技能、自我评价、工作经历、项目经历、证书，边填边自动存草稿 |
| 3 | **智能优化** | 查看匹配度评分、简历体检清单、逐条改写建议、自我评价重写、技能按 JD 相关度重排 |
| 4 | **预览导出** | 右侧实时预览成品简历，可打印存 PDF，或复制 Markdown / 纯文本 |

填完第 2 步后，第 3、4 步会自动更新，无需手动触发。

## 其他说明

- **数据存在你自己浏览器里**，不经过任何服务器。换设备或换浏览器时，用右上角「导出备份」下载 JSON，再到新设备「导入恢复」即可。
- **分享链接分享的是工具本身**：别人打开看到的是示例数据和他自己填的内容，看不到你填的简历。
- 想本地使用：直接双击 `index.html` 就能打开，无需安装任何东西。
